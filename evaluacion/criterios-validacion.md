## 3. Comprobación práctica antes de aplicar

Antes de convocar participantes, realizar una revisión interna del protocolo:

1. Abrir cada archivo y comprobar que las tablas y campos se visualizan correctamente.
2. Recorrer las seis tareas en el prototipo, sin registrar esa revisión como resultado de participantes.
3. Confirmar que cada consigna puede completarse en la versión que se evaluará.
4. Comprobar que el evaluador puede registrar inicio, finalización y duración.
5. Simular el cálculo de tasa de éxito con datos ficticios y el cálculo SUS con el ejemplo ilustrativo.
6. Verificar que las hojas no solicitan información personal.
7. Corregir cualquier instrucción ambigua y guardar una versión final de los instrumentos.

## 4. Condiciones para considerar preparado el protocolo

El protocolo se considerará **preparado para la Fase 2** cuando:

- Todos los criterios aplicables de la lista estén marcados como “Cumple”.
- Las seis tareas hayan sido contrastadas con la versión concreta del prototipo.
- Las instrucciones, escalas y fórmulas sean consistentes entre los documentos.
- El evaluador pueda registrar una sesión completa sin campos esenciales pendientes.
- Se haya confirmado que no se recopilarán datos personales innecesarios.
- Viviana haya recibido los cuatro archivos.

Si algún criterio esencial no cumple, el protocolo todavía no debe considerarse listo. Se debe corregir y volver a revisar.
