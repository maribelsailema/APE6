## B. Instrucciones para el evaluador

1. Asignar un código anónimo al participante.
2. Leer la consigna de cada tarea sin explicar cómo resolverla.
3. Iniciar el cronómetro cuando la persona comience a interactuar.
4. Detenerlo cuando alcance el resultado esperado, abandone o se determine que no puede continuar.
5. Registrar acciones observables, errores, dificultades y solicitudes de ayuda.
6. No corregir ni completar acciones por la persona. Si se requiere intervenir, registrar el motivo y el tipo de ayuda.
7. Aplicar el cuestionario SUS al finalizar las seis tareas.

**Códigos sugeridos:**  
Resultado: C = completada correctamente; I = incompleta; X = resultado incorrecto; NA = no aplicada.  
Error: EC = crítico; ENC = no crítico.  
Ayuda: AS = solicitada por participante; AO = ofrecida por evaluador.
